## Context

`docs/RFC/ToDo/issue-118/000-initial-work/phases/phase-008.md`.

The **functional implementation of Phase 008 is correct and complete** — every behavioral exit
criterion is met (verified by reading the source, running the full frontend suite, the vite build, and

here so the human committing the work knows the committed `dist/index.html` currently points at a stale
