# No assistant mentions

## Rules

1. Never write the name of the AI coding assistant doing the work, its model or its vendor in any file in this repo: code, comments, docs, configs, or file and folder names.
2. Never add files or folders tied to one coding agent, such as an instruction file named after an agent or a dot-folder for one agent's settings. Agent instructions live only in `AGENTS.md` and `.agents/skills/`.
3. The same applies to text you draft for humans to use, such as commit messages and PR descriptions.
4. No "generated by" or "written with" notes, no co-author trailers, no assistant links or badges.
5. Before finishing a task, search the changed files (case-insensitive) for the assistant's and vendor's names and remove any hit that refers to the coding assistant.

## Model and provider IDs are not mentions

PenguiFlow is an LLM library. Model IDs and provider names that the library needs to work are product content, not assistant mentions: model routing, provider profiles, pricing, their tests, and the docs, example `.env` files and templates that show which models to configure. Keep those, and don't rename or remove them to satisfy rule 5.
